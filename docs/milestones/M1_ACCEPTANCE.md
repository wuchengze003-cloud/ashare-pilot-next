# M1：第一次真实取数验收标准

- 基线：`a676775f6120907cd489bee1c1a43bf20c071445`
- 状态：验收口径冻结
- 窗口：`2023-06-01` 至 `2023-10-31`
- 范围：20 只审计用标的，包含正常上市、窗口内可验证退市边界和有历史停牌证据的证券

M1 只验证一条真实供应商行情能否经过不可变原始快照、标准化、
质量和覆盖审计、原子发布，最终产出可由 `dataset_id` 读取的数据集。
它不验证策略有效性或可交易收益。

取数窗口和数据集 `as_of` 固定为 `2023-06-01` 至 `2023-10-31`。
`as_of`、`generated_at`、运行标识和输出根目录全部由调用方显式传入。M1 使用
`trade_cal`、`stock_basic`、`daily`、`adj_factor` 和 `suspend_d`。不根据 `daily`
缺行反推停牌。

标的只用于验证数据边界，不是策略 Universe 或推荐股票。实现必须在采集开始时
用当次 `stock_basic` 和 `suspend_d` 响应重新验证状态；供应商记录若发生实质变化，
先修订本文档，不在运行时静默换股。

## 产物和边界

- 真实原始响应、标准化行情、Dataset Manifest、Coverage Audit、采集遥测和拒绝记录
  全部写入已忽略的 `runtime/`，不追踪到 Git。
- 数据先写入临时目录；文件哈希、Schema、覆盖率和质量全部通过后才原子移动
  数据目录，最后原子发布 Manifest。失败运行不得覆盖上一完整数据集。
- Git 只保留实现、测试、文档和纯合成样例。
- 不复制或链接旧项目的 runtime、数据文件、SQLite、报告、环境文件或部署状态。
  旧项目只能用于只读核对供应商行为、字段单位和测试意图。
- M1 不做复权应用、策略、回测、赛马、全市场历史扩展、主动限流、Web 或生产发布。

## 验收条件

### AC-1：覆盖审计零静默跳过

对每个位于成员有效期内的开市成员日，只允许四种结果：

1. 存在已验证的 `daily` bar；
2. 不存在 bar，但同一证券、同一交易日存在 `suspend_d` 停牌证据；
3. 当日是已验证的 `delist_date`，且不存在 bar 或停牌证据，分类为
   `EXPECTED_DELISTED`；
4. `MISSING`。

`MISSING` 计数必须为 0，`silent_skip_symbols` 必须为空。退市日之后的日期由
`SecurityLifecycle` 排除在预期成员日之外；退市当日只记录一次，不伪装成停牌
或无解释缺失。bar、停牌和退市证据同日重叠时按 bar、停牌、退市的顺序只计一次。

现有 Coverage Audit 1.0 无法结构化表示 `EXPECTED_DELISTED`。M1 实现必须以新主版本
合同表示该类别，保留 1.0 Schema 不变，并同时提交生产者、消费者和 Schema 测试。

`stock_basic` 中不符合当前 A 股代码合同的供应商记录必须失败关闭或进入结构化
拒绝证据；不得静默丢弃、自动改写代码或进入标准化数据集。对 `L`、`D`、
`P` 三种状态分别满足 `raw_rows = accepted_rows + rejected_rows`；空集合是有效结果。

### AC-2：取数内容确定性

使用完全相同的显式参数连续取数两次：

- 标准化文件的规范化字节和 `files[*].sha256` 必须一致；
- `dataset_id` 必须由数据内容和稳定合同身份派生，两次必须一致；
- 供应商返回顺序、分页边界和字段顺序不得改变内容身份。

`generated_at`、请求耗时和重试次数不属于数据内容身份，不要求两次整份 Manifest
逐字节相同。

### AC-3：重放确定性和篡改阻断

同一已验证 `dataset_id` 连续重放两次，特征重放的规范化字节必须一致。阴性对照修改
一条 bar 的 `close` 但不更新 Manifest，加载必须因文件哈希不匹配而失败，不得进入
Research 或 Signal Runner。

### AC-4：成本模型跨分段激活

对同一沪深 A 股卖出金额：

- `2023-08-27` 的印花税率为 `0.1%`；
- `2023-08-28` 的印花税率为 `0.05%`。

现有成本黄金样例必须继续通过，M1 不修改成本金融语义。

### AC-5：单位和价格量级验证

原始 Tushare 字段按 `vol=手`、`amount=千元` 解读，标准化后必须为
`volume=股`、`amount=元`：

```text
volume = vol * 100
amount = amount_raw * 1000
implied_vwap = amount / volume
```

对每条 `volume > 0` 的真实 bar，`implied_vwap` 必须为有限正数，并落在当日
`[low * 0.95, high * 1.05]` 内。越界记录必须作为结构化质量问题输出并使数据集失败；
不使用固定的 1 元下限，因为真实低价和退市整理期行情可低于 1 元。

### AC-6：新鲜度门禁失败关闭

显式 `as_of` 比数据最后完整交易日晚 10 个已完成交易日时：

- Data Gateway 的新鲜度证据必须失败并包含 `DATA_STALE`；
- 存在可信前序信号时，Signal Runner 必须产出 `HOLD` 并保持上一目标仓位；
- 不存在可信前序信号时，按已接受状态机失败关闭，不伪造 `HOLD` 仓位。

### AC-7：无隐式当前时间

生产源码不得读取 `datetime.now()`、`date.today()`、`time.time()` 或等价墙上时间。
`as_of`、`generated_at` 和采集窗口全部显式传入。耗时采集只允许使用可注入的单调时钟，
且不影响数据内容身份。

### AC-8：请求遥测可审计

每次采集必须在同一不可变运行目录中产出独立遥测证据，至少包含：

- 每个接口的高层逻辑调用数；
- 实际 HTTP 请求尝试总数，而不是高层方法调用数；
- 单调总耗时；
- 分页数、重试数、限频错误数和其他短暂错误数；
- 每个供应商接口的实际 HTTP 尝试数、成功数和失败数。

每次 transport send 都计为一次 HTTP 尝试；分页和每次重试都单独计数。限频错误同时
计入短暂错误。不使用预先假设的请求总数代替真实 transport 计数。

遥测不写入 Dataset Manifest 2.0，也不参与 `dataset_id` 或文件内容哈希。这避免
非确定耗时污染数据身份，也避免在 M1 无意中改变已发布合同。

## 实现和审查停止规则

M1 实现仅在通过以下全部检查时验收：

```bash
uv run ruff check .
uv run pytest
uv run python tools/validate_contracts.py
uv run python tools/check_boundaries.py
```

评审只判定 AC-1 至 AC-8 和现有仓库边界是否满足。AC 之外的改进建议单独记录，
不扩大 M1 实现范围。
