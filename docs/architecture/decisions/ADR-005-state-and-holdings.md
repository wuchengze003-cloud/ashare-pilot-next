# ADR-005：降级状态和真实持仓边界

- 状态：已接受
- 日期：2026-07-29

## 决定

第一版系统只发布目标仓位，不连接券商，不拥有真实持仓，不生成“已成交”结论。
Web必须把目标、用户确认和真实成交区分开。

状态优先级和转换见[`../STATE_MACHINE.md`](../STATE_MACHINE.md)。

## 执行边界

- Signal Runner输出目标权重和原因，不输出券商订单状态。
- 系统不处理部分成交、撤单或次日继续卖出。
- 未来自动交易必须使用独立`execution_adapter`合同。
- 未接入执行适配器前，任何产物不得包含`filled`、`executed`或等价声明。
